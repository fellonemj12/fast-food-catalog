# Fast Food Ordering Catalog

An interactive and responsive fast-food menu catalog built using standard web technologies.

## Features
* *Dynamic Menu:* Renders product items dynamically using JavaScript.
* *Interactive Cart:* Real-time quantity adjustments, item count updates, and total price calculation.
* *Responsive Layout:* Clean CSS styling designed for both desktop and mobile views.
* *Live Deployment:* Published using GitHub Pages.

## Live Demo
Access the live application here: [https://fellonemj12.github.io/fast-food-catalog/](https://fellonemj12.github.io/fast-food-catalog/)

## Tech Stack
* *HTML5* - Structure and layout
* *CSS3* - Custom styling and responsiveness
* *JavaScript (ES6+)* - Dynamic DOM manipulation and state tracking
